# Box Office Champions

This project is an academic assignment for the ITVarsity web development course. It showcases the top 25 highest-grossing movies of all time, using data sourced from Box Office Mojo and Wikipedia (as of October 2025).

## Features

- Responsive web design for desktop and mobile devices
- Stylish navigation menu loaded dynamically via JavaScript
- Table displaying movie rank, year, title, and worldwide box office earnings
- Clean, modern UI with gradients and table styling
- Accessible navigation and semantic HTML

## Technologies Used

- HTML5
- CSS3
- JavaScript (vanilla)

## How to Use

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Navigate between Home, Top Movies, and About pages using the menu.

## Academic Context

This project was developed as part of the ITVarsity web development curriculum to practice and demonstrate skills in:

- HTML structure and semantics
- CSS styling and responsive layouts
- JavaScript DOM manipulation and dynamic content loading
