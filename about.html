About This Project

This project was created to showcase the top 25 highest grossing movies of all time. The data is sourced from Box Office Mojo and is accurate as of October 2025.

This web project was developed as a part of ITVarsity web development course to practice HTML, CSS.

The project demonstrates how to style tables, use gradients and simple navigation menus.

It also includes responsive design principles to ensure a seamless experience across devices.

All data is based on the latest information from Wikipedia as of October 2025.
